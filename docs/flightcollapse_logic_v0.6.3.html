3
Junction curation
Junctions are curated BEFORE chains are built. A chain with 40 reads containing one spurious junction survives a chain threshold; it does not survive a junction threshold.
An ANNOTATED junction is never rejected — dropping one because it is rare in a single sample would fabricate novel chains out of well-known transcripts.
a junction that is still novel must clear
  • molecules ≥ 3 and reads ≥ 5
    not read count alone — reads are PCR copies
  • ≥ 0.1% of the reads at its own donor AND its own acceptor
  • GT-AG always; GC-AG and AT-AC only with short-read confirmation in ≥ 2 replicates, or ≥ 50 reads
  • no direct repeat ≥ 8 bp flanking the intron
    RT template switching
  • local FDR ≤ 0.05 from the calibrated model
the calibrated model
Ridge logistic → two-component mixture → local FDR, with Storey π₀ and a monotone fit, stratified by whether the junction reuses an annotated splice site. Annotated junctions are the positive anchor; junctions on rejected reads are the negative one.
Fitted PER CONTIG — which is exactly what makes panel 0's parallelism safe: no calibration crosses a contig boundary, so splitting the run changes no threshold and no decision.

Rule 2 — end3_novel must earn its 3' end
On SIRV Set 4 this category was wrong 12/12 in the reference arm and 11/11 in the masked arm. The mechanism is internal priming: oligo-dT anneals to a genomic A-stretch inside the transcript, and the resulting pile accumulates support exactly like a real cleavage site.
Three things that cannot separate them. A read floor cannot — false ends reach p90 548 reads while true ones go down to 5. tail_molecule_frac cannot — 0.96 vs 1.00 on BD176c — because it scores an A-run without asking what the genome says underneath. And cross-sample reproducibility cannot: an internal-priming site recurs in every library made from the same genome, so a model called in all three HEK samples is not thereby real.

A genuine poly(A) tail is not in the genome. Everything needed was already being measured — reads.tail_len per read since 0.1.17, genome.fetch since the beginning — and nothing compared the two.
Defaults: excess ≥ 8 bp on ≥ 50% of the model's reads, scanning 60 bp downstream. This is why the collapse must read the UNTRIMMED dedup BAM: a trimmed read has no terminal A-run and the tier would silently have no opinion.

tier 3 · a contrast, not an absolute cut
A real 3' end has a U/GU-rich downstream element at +5…+30; an internal-priming site is A-rich. The tier scores (G+U) − A ≥ 0.10 rather than an absolute G+U threshold, because the window is ~25 bases and an absolute 0.45 cut is one base away from 0.40 — neutral sequence crosses it by chance about half the time. Neutral sequence sits near +0.25; an internal-priming site goes sharply negative.
A single perc_a_downstream number cannot express this: on BD176c it moves only 20 → 25 between FSM and end3_novel. Peak dispersion does separate them — FSM 4.1 bp against end3_novel 34.6 bp — so a tight peak is required alongside.
why gene_dominant is LAST
Used first it selects against the biology. A genuine proximal polyA site usually carries a minority of a gene's molecules, while a strong internal-priming site in a well-expressed gene is exactly the thing that becomes dominant. It exists to rescue models the evidence tiers cannot speak to — 1.2% of survivors — not to adjudicate the ones they can.

the separation is the point
The first pass is unchanged: same reads, same junction curation, same suffix resolution, same 3'-peak clustering, same models. The second pass runs afterwards on the catalogue the first pass produced, and may only keep a model, remove it, or replace it with an explicitly inferred one. It never builds a structure from scratch.
A filter folded into model construction cannot be turned off, cannot be compared against its own absence, and cannot report what it cost. This one writes one row per decision and can be disabled with a flag — --no-second-pass reproduces the 0.4.6 catalogue from the same binary.

0
Contig-parallel execution
A contig's result depends on no other contig, and all three calibrated models are fitted per contig already — so distributing contigs across processes changes no calibration, no threshold and no decision.
What is genuinely shared is small and all of it lives in the parent: model IDs and the PB.N gene numbering (assigned in contig order), read_stat and group (stitched from per-contig shards), and the molecule matrix (accumulated from count shards). fork only — under spawn every worker would re-read the GTF, which costs more than the parallelism saves.
BD144_kin, summed contig work2.24 h
wall clock at −j 80.65 h
speed-up3.5×
floor set by the slowest contig (chr1)997 s = 43% of wall
Longest-first dispatch, so the tail is not a whole chr1 long. Memory, not cores, is the binding constraint: peak RSS ≈ workers × per-contig peak, and worker_count() clamps against MemAvailable.
0.5.1 · a killed worker no longer hangs the run
multiprocessing.Pool has no abrupt-death detection. When a worker is SIGKILLed — the OOM killer is how that happens here — the pool quietly forks a replacement, but the task it was holding produces no result and imap_unordered waits for it forever.
Observed: BD144_kin sat at 23 of 24 contigs for two and a half hours with every worker idle and nothing in the log. The parent now tracks which pid owns which contig, notices when one disappears, and re-runs that contig itself — serially, in the parent, after the pool closes, because if the cause was memory then re-dispatching into a full pool would just kill it again.

Rule 1 — same chain, 3′ ends within 200 bp
Models are partitioned by contig, strand and exact intron chain, so the rule can never merge two splice structures. Within a partition the representative is the annotated 3′ end if there is one, then the best supported, then the longest. Everything within the tolerance of that representative is absorbed.

Rule 2 — reference-free sub-chain (fragment) filter
A model is removed, and its reads folded into the container, when its ordered intron chain is a contiguous sub-chain of a longer model on the same contig and strand (junctions ±5 bp), its terminal exons lie inside the matching exons of that model (±50 bp), and the container carries ≥ 2× its support.

Why the two ends are not treated alike
The 3′ end is a position — the mode of a cleavage-site peak — and only a tolerance can say whether two of them are the same site. The 5′ end is a containment relation between two intron chains, which the sub-chain filter decides from structure alone, with no annotation and no distance threshold.
this asymmetry is the design, not an accident of tuning
